MakerOS; ARM64 tabanlı, Pi 4 uyumlu kartlar için bağımsız ve açık kaynaklı bir Linux işletim sistemi. Web masaüstü, Rust sistem servisleri, A/B güncelleme, yerel yapay zekâ asistanı ve cihazın içinde çalışan eklentiler tek bir bütünde. MakerOS is an independent, open-source Linux operating system for ARM64, Pi 4 compatible boards. Web desktop, Rust system services, A/B updates, an on-device AI assistant and plugins that run on the board, in one cohesive system.

ÖzelliklerFeatures

Hazır bir dağıtıma giydirilmiş tema değil.Not a theme on top of someone else's distro.

Önyükleme zincirinden masaüstüne kadar her katman MakerOS için tasarlandı: anlaşılır, değiştirilebilir ve hafif.Every layer, from the boot chain to the desktop, is built for MakerOS: understandable, hackable and lightweight.

Sağlam tabanSolid foundation

Her yerde aynı masaüstüOne desktop, everywhere

Kartın ekranında, ağdaki bir bilgisayarda ya da telefonda aynı pencereli deneyim.The same windowed experience on the board's display, any computer on your network, or your phone.

makerd ailesi: HTTP/WS API, ayrıcalık ayrımı, PTY terminal ve kullanıcı süreçleri.The makerd family: HTTP/WS API, privilege separation, PTY terminal and user processes.

Yerel AI asistanıOn-device AI

Python ve otomasyonPython & automation

uv tabanlı proje yöneticisi, hazır şablonlar, Otomatik Başlatma ve Cron zamanlayıcı.uv-based project manager, ready templates, Autostart and Cron scheduling.

KurulumSetup

Tek komut: kur ya da güncelle.One command: install or update.

Betik en son sürümü indirir, doğrular ve kartın nasıl bağlı olduğunu sorar: kart okuyucudaysa baştan yazar, Pi'nin içindeyse USB-C üzerinden günceller.The script downloads the latest release, verifies it and asks how the card is connected: in a card reader it writes it from scratch, inside the Pi it updates over USB-C.

Terminal'i açın (macOS: Spotlight'ta "Terminal" yazın) ve şu satırı yapıştırıp Enter'a basın:Open Terminal (macOS: type "Terminal" in Spotlight), paste this line and press Enter:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ferhatozcelik/maker-os/main/flash.sh)"

Komut önce bağlantı türünü sorar: 1) SD — kart bilgisayardaki kart okuyucuda, baştan yazılır (yeni kurulum). 2) USB — kart Pi'nin içinde, Pi USB-C ile bağlı; MakerOS güncellenir, dosyalarınız korunur (yönetici hesabıyla giriş, varsayılan maker / maker).The command first asks how the card is connected: 1) SD — card in your computer's card reader, written from scratch (fresh install). 2) USB — card inside the Pi, Pi connected over USB-C; MakerOS is updated and your files are kept (sign in with an admin account, default maker / maker).

Yönetici parolanız istenebilir. USB-C portu Pi'yi beslemeye yetmezse beslemeli bir USB hub kullanın. Betiği indirip incelemek isterseniz: flash.shYou may be asked for your password. If the USB-C port cannot power the Pi, use a powered USB hub. To download and inspect the script: flash.sh

En kolayı: flash.cmd dosyasını indirip çift tıklayın ve yönetici iznini onaylayın. Ya da Başlat menüsünde PowerShell'e sağ tıklayıp Yönetici olarak çalıştır'ı seçin ve yapıştırın:Easiest: download flash.cmd, double-click it and allow administrator access. Or right-click PowerShell in the Start menu, choose Run as administrator and paste:

irm https://raw.githubusercontent.com/ferhatozcelik/maker-os/main/flash.ps1 | iex

Yazma bittikten sonra Windows kartı biçimlendirmeyi önerirse İptal'e basın. Windows'ta yalnız SD (kart okuyucu) modu vardır; USB modu macOS ve Linux içindir. Betik: flash.ps1If Windows offers to format the card after writing, click Cancel. Windows supports SD (card reader) mode only; USB mode is for macOS and Linux. Script: flash.ps1

    Yalnız harici diskler listelenir. Bilgisayarınızın diski asla gösterilmez; disk adını yazarak onaylarsınız.Only external disks are listed. Your computer's disk is never shown; you confirm by typing the disk name.

  2. BaşlatınBoot

GeliştiricilerDevelopers

Bir klasör, bir eklenti.One folder, one plugin.

Eklenti; plugin.json, pyproject.toml ve main.py'den oluşan bir Python klasörüdür. MakerOS onu kendi kullanıcı hesabınızla uv run ile çalıştırır ve arayüzünü pencerede, widget'ta ya da telefonda gösterir. Derleme ya da yayın adımı yok: klasör depoya girdiği an mağazadadır.A plugin is a Python folder with plugin.json, pyproject.toml and main.py. MakerOS runs it as your user with uv run and shows its UI in a window, a widget or on your phone. No build or release step: once the folder lands in the repository, it is in the store.

# 1. Şablonu oluştur (MakerOS terminali)
$ mos plugin new sensor-panel

# 2. plugins/sensor-panel/plugin.json
{
  "id": "sensor-panel",
  "name": "Sensör Paneli",
  "version": "1.0.0",
  "entrypoint": "main.py",
  "web_port": 8799,
  "icon": "icon.svg",
  "widget": { "path": "/widget", "w": 320, "h": 200 }
}

# 3. Denetle ve dene, sonra PR aç
$ python3 tools/build.py
$ python3 tools/smoke.py sensor-panel
